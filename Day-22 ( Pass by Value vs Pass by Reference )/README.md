## 💡 Problem: Pass by Value vs Pass by Reference

**Difficulty:** Easy
**Topic:** Functions • Pass by Value • Pass by Reference

### 🧠 What I Learned

Today I learned about the difference between **Pass by Value** and **Pass by Reference** in functions.

In **Pass by Value**, a copy of the variable is passed to the function, so changes made inside the function do not affect the original variable.

In **Pass by Reference**, the function works with the original variable, so changes made inside the function affect the original variable.

### 🔄 Basic Logic

If:

```text
a = 10
````

Using **Pass by Value**:

```text
changeValue(a)
```

The function receives a copy:

```text
Original value = 10
Inside function = 20
Original value remains = 10
```

Using **Pass by Reference**:

```text
changeReference(a)
```

The function works with the original variable:

```text
Original value = 10
Inside function = 20
Original value becomes = 20
```

The main difference is:

```text
Pass by Value     → Copy is passed → Original value unchanged
Pass by Reference → Original is accessed → Original value changes
```

This helped me understand how functions can either work with a **copy of data** or directly with the **original variable**.
