## 💡 Problem: Declare and Print an Array

**Difficulty:** Easy
**Topic:** Arrays Basics • Array Declaration • Array Traversal

### 🧠 What I Learned

Today I learned how to **declare an array, store multiple values, and print its elements**.

An array is a collection of elements of the same data type stored together. Each element can be accessed using its **index**, starting from `0`.

### 🔄 Basic Logic

If:

```text
Array = {10, 20, 30, 40, 50}
````

The elements are stored at different indexes:

```text
Index:   0   1   2   3   4
Value:  10  20  30  40  50
```

To print all elements, we can use a loop:

```text
for (int i = 0; i < 5; i++)
{
    print(arr[i]);
}
```

The loop accesses each element one by one:

```text
arr[0] → 10
arr[1] → 20
arr[2] → 30
arr[3] → 40
arr[4] → 50
```

So the output is:

```text
10 20 30 40 50
```

The main idea is to **declare an array, access its elements using indexes, and traverse the array using a loop**.
