## 💡 Problem: Intersection of Two Arrays

**Difficulty:** Easy
**Topic:** Arrays • Basic Math • Hashing

### 🧠 What I Learned

Today I learned how to **find the common elements between two arrays**.

The intersection of two arrays contains the elements that appear in both arrays. We can use loops, sorting, or a hash set to identify common elements efficiently.

For this example, each common element is included only once.

### 🔄 Basic Logic

If:

```text
arr1 = {1, 2, 2, 3, 4}
arr2 = {2, 3, 5, 6}
````

Then:

```
Common elements → 2, 3
```

The elements `2` and `3` appear in both arrays. The repeated `2` in the first array is included only once.

So the output is:

```
2 3
```

We can store the elements of one array in a hash set and check which elements from the other array are present. Another set can help avoid duplicate results.
