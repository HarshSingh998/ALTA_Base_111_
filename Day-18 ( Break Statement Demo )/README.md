## 💡 Problem: Break Statement Demo

**Difficulty:** Easy
**Topic:** Programming Basics • Loops • Break Statement

### 🧠 What I Learned

Today I learned how to use the **`break` statement** to immediately stop a loop when a specific condition is met.

In this problem, the program keeps reading integers and adding the positive numbers. As soon as `0` or a negative number is encountered, the loop stops using `break`.

### 🔄 Basic Logic

If:

```text
10 25 5 18 -1 30
````

The program processes the numbers one by one:

```text
10 → Sum = 10
25 → Sum = 35
5  → Sum = 40
18 → Sum = 58
```

Now the next number is:

```text
-1
```

Since:

```text
-1 <= 0
→ true
```

The `break` statement immediately terminates the loop.

The number `30` is **not processed** because the loop has already stopped.

So the output is:

```text
Sum before break: 58
```
