## 💡 Problem: Fibonacci Series (Iterative)

**Difficulty:** Easy
**Topic:** Programming Basics • Loops • Fibonacci Series

### 🧠 What I Learned

Today I learned how to generate the **Fibonacci series** using an iterative approach.

In the Fibonacci series, the first two numbers are `0` and `1`. Every next number is calculated by adding the previous two numbers.

### 🔄 Basic Logic

If:

```text
N = 7
````

The series starts with:

```text
a = 0
b = 1
```

Now calculate the next terms by adding the previous two numbers:

```text
0 + 1 = 1
1 + 1 = 2
1 + 2 = 3
2 + 3 = 5
3 + 5 = 8
```

So the first 7 Fibonacci numbers are:

```text
0 1 1 2 3 5 8
```

The basic logic is:

```text
next = a + b
a = b
b = next
```

The values keep changing after every iteration:

```text
a = 0, b = 1
a = 1, b = 1
a = 1, b = 2
a = 2, b = 3
a = 3, b = 5
a = 5, b = 8
```

The main idea is to **keep track of the previous two numbers and calculate the next number by adding them together**.
