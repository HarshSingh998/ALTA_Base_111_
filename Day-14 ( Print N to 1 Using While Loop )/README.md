## 💡 Problem: Print N to 1 Using While Loop

**Difficulty:** Easy
**Topic:** Programming Basics • While Loop • Decrement

### 🧠 What I Learned

Today I learned how to use a **while loop** to print numbers in reverse order, starting from `N` and continuing down to `1`.

A `while` loop repeatedly executes a block of code as long as the given condition is `true`.

### 🔄 Basic Logic

If:

```text
N = 5
````

The loop starts from `N` and decreases the value by `1` after every iteration:

```text
n = 5 → print 5
n = 4 → print 4
n = 3 → print 3
n = 2 → print 2
n = 1 → print 1
```

So the output is:

```text
5 4 3 2 1
```

The basic loop structure is:

```text
while (n >= 1) {
    print(n);
    n--;
}
```

Here:

```text
n >= 1    → Loop condition
print(n)  → Print current value
n--       → Decrease n by 1
```

The main idea is to **start from `N` and keep decreasing the value until it reaches `1`**.

## 🎯 What I Learned From This Problem

* `while` loop
* Loop condition
* Decrement operator `--`
* Reverse counting
* Iteration
* Working with user input
* Understanding loop flow
* Printing numbers in reverse order

This problem helped me understand how a **while loop can be used when we want to repeat a task while a condition remains true**, and how decrementing a variable can create a reverse sequence.
