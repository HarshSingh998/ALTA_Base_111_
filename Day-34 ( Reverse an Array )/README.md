## 💡 Problem: Reverse an Array

**Difficulty:** Easy
**Topic:** Arrays • Array Traversal • Two-Pointer Technique

### 🧠 What I Learned

Today I learned how to **reverse an array**, which means changing the order of its elements from last to first.

We can reverse an array by swapping the first element with the last, the second element with the second-last, and continuing until we reach the middle.

### 🔄 Basic Logic

If:

```text
arr = {10, 20, 30, 40, 50}
````

Then:

```
Swap 10 and 50 → {50, 20, 30, 40, 10}
Swap 20 and 40 → {50, 40, 30, 20, 10}
```

The middle element remains in its position.

So the output is:

```
50 40 30 20 10
```

We can use two pointers, one at the beginning and one at the end, and move them toward the middle while swapping elements.

- Using loops and conditions

- Improving time and space efficiency

This problem helped me understand how to reverse an array efficiently using a single traversal from both ends without creating another array.
