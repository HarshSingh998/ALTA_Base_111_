## 💡 Problem: Check Leap Year

**Difficulty:** Easy
**Topic:** Programming Basics • If-Else • Conditional Logic

### 🧠 What I Learned

Today I learned how to check whether a given year is a **leap year** using `if-else` conditions.

A leap year usually occurs when a year is divisible by `4`. However, years divisible by `100` are not leap years unless they are also divisible by `400`.

### 🔄 Basic Logic

If:

```text
Year = 2024
````

First, check whether the year is divisible by `400`:

```text
2024 % 400 == 0
→ false
```

Then check whether it is divisible by `4` and not divisible by `100`:

```text
2024 % 4 == 0
→ true

2024 % 100 != 0
→ true
```

Since the required conditions are satisfied:

```text
2024 is a Leap Year
```

So the output is:

```text
2024 is a Leap Year
```

The main idea is to **use divisibility rules and conditional statements to determine whether a year is a leap year**.
