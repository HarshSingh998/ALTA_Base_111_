## 💡 Problem: Largest of Three Numbers

**Difficulty:** Easy
**Topic:** Programming Basics • Nested If-Else • Conditional Statements

### 🧠 What I Learned

Today I learned how to find the **largest number among three integers** using nested `if-else` statements.

In this problem, I cannot use logical AND operator `&&` or the built-in `max()` function. So, I compare the numbers step-by-step using nested conditions.

### 🔄 Basic Logic

If:

```text
A = 45
B = 89
C = 23
````

First, compare `A` and `B`:

```text
45 > 89
→ false
```

So, `B` is greater than `A`.

Now compare `B` with `C`:

```text
89 > 23
→ true
```

Therefore:

```text
Largest Number = 89
```

So the output is:

```text
The largest number is: 89
```

The main idea is to **compare two numbers first and then compare the winner with the third number**.
