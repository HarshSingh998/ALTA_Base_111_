## 💡 Problem: Divisible by Both 3 and 5

**Difficulty:** Easy
**Topic:** Programming Basics • If-Else • Modulo Operator

### 🧠 What I Learned

Today I learned how to check whether a number is **divisible by 3, divisible by 5, divisible by both, or neither**.

The modulo operator `%` helps us check whether a number is exactly divisible by another number. If the remainder is `0`, the number is divisible.

### 🔄 Basic Logic

If:

```text
N = 15
````

First, check divisibility by `3`:

```text
15 % 3 == 0
→ true
```

Then, check divisibility by `5`:

```text
15 % 5 == 0
→ true
```

Since the number is divisible by both:

```text
Divisible by both 3 and 5
```

So the output is:

```text
Divisible by both 3 and 5
```

The main idea is to **use the modulo operator and if-else conditions to check different divisibility cases**.
