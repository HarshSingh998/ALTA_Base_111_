## 💡 Problem: BMI Category

**Difficulty:** Easy
**Topic:** Programming Basics • Nested If-Else • Conditional Logic

### 🧠 What I Learned

Today I learned how to calculate **BMI (Body Mass Index)** using weight and height, and then classify the calculated value into different categories using **nested if-else statements**.

The BMI formula is:

```text
BMI = weight / (height × height)
````

After calculating BMI, conditional statements are used to determine the appropriate category according to the ranges given in the problem.

### 🔄 Basic Logic

If:

```text
Weight = 70.0 kg
Height = 1.75 m
```

First, calculate BMI:

```text
BMI = 70 / (1.75 × 1.75)
    = 70 / 3.0625
    = 22.86
```

Now check the BMI range:

```text
22.86 < 18.5
→ false
```

So, check the next condition:

```text
22.86 < 25
→ true
```

Therefore:

```text
Category = Normal weight
```

So the output is:

```text
BMI: 22.86
Category: Normal weight
```

The main idea is to **calculate BMI first and then use nested if-else conditions to determine the category**.
