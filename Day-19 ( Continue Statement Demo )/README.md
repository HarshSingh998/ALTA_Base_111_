## 💡 Problem: Continue Statement Demo

**Difficulty:** Easy
**Topic:** Programming Basics • For Loop • Continue Statement

### 🧠 What I Learned

Today I learned about the **`continue` statement** and how it is used to **skip a particular iteration** of a loop.

The `continue` statement skips the remaining part of the current iteration and moves directly to the next iteration of the loop.

### 🔄 Basic Logic

If:

```text
N = 10
````

We check every number from `1` to `N`.

If the number is divisible by `3`:

```text
if (i % 3 == 0)
    continue;
```

Then that number is skipped.

For example:

```text
3  → skipped
6  → skipped
9  → skipped
```

The remaining numbers are printed:

```text
1 2 4 5 7 8 10
```

So the output is:

```text
1 2 4 5 7 8 10
```

The `continue` statement is useful when we want to **skip specific values or conditions without stopping the entire loop**.
