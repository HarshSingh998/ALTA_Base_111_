## 💡 Problem: Print 1 to N Using For Loop

**Difficulty:** Easy
**Topic:** Programming Basics • For Loop • Iteration

### 🧠 What I Learned

Today I learned how to use a **for loop** to print all natural numbers starting from `1` up to a given number `N`.

A `for` loop is useful when we know how many times we need to repeat a particular task.

### 🔄 Basic Logic

If:

```text
N = 5
````

The loop starts from `1` and continues until `N`:

```text
i = 1 → print 1
i = 2 → print 2
i = 3 → print 3
i = 4 → print 4
i = 5 → print 5
```

So the output is:

```text
1 2 3 4 5
```

The basic loop structure is:

```text
for (int i = 1; i <= n; i++)
```

Here:

```text
i = 1       → Starting value
i <= n      → Loop condition
i++         → Increase i by 1
```

The main idea is to **start the loop from `1` and continue incrementing the value until it reaches `N`**.
