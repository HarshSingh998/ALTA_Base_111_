## 💡 Problem: Function Returning Multiple Values

**Difficulty:** Easy
**Topic:** Functions • Return Values • Multiple Values

### 🧠 What I Learned

Today I learned how a **function can return multiple values** and how those values can be stored and used in the program.

In C++, a function normally returns a single value. To return multiple values, we can use methods like **arrays, structures, pairs, or references**.

### 🔄 Basic Logic

If a function needs to return two values:

```text
First value = 10
Second value = 20
````

We can use a `pair`:

```text
return {10, 20};
```

The returned values can then be stored separately:

```text
first = 10
second = 20
```

So the basic flow is:

```text
Function
   ↓
Calculate multiple values
   ↓
Return the values
   ↓
Store and use the returned values
```

For example:

```text
add(10, 20)
```

can return:

```text
Sum = 30
Difference = -10
```

This helps us organize related results and return them together from a function.
