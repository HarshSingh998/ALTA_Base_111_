## 💡 Problem: Check if an Array Is Sorted

**Difficulty:** Easy
**Topic:** Arrays • Array Traversal • Basic Logic

### 🧠 What I Learned

Today I learned how to **check whether an array is sorted in ascending order**.

An array is sorted in ascending order when every element is smaller than or equal to the next element.

We can check this by comparing each element with the element next to it. If any element is greater than the next element, the array is not sorted.

### 🔄 Basic Logic

If:

```text
arr = {10, 20, 30, 40, 50}
````

Then:

```
10 <= 20  ✓
20 <= 30  ✓
30 <= 40  ✓
40 <= 50  ✓
```

So the output is:

```
Array is sorted
```

Now, if:

```
arr = {10, 30, 20, 40, 50}
```

Here, `30 > 20`, so the array is not sorted.

```
Array is not sorted
```

We can solve this problem using a loop and comparisons without sorting the array.
