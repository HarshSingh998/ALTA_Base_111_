## 💡 Problem: Simple Calculator Using Switch Case

**Difficulty:** Easy
**Topic:** Programming Basics • Switch Case • Arithmetic Operators

### 🧠 What I Learned

Today I learned how to create a **simple calculator using the switch-case statement**.

The program takes two numbers and an operator such as `+`, `-`, `*`, `/`, or `%`, and then performs the corresponding arithmetic operation.

### 🔄 Basic Logic

If:

```text
A = 12
B = 4
Operator = /
````

The `switch` statement checks the operator:

```text
Operator = '/'
→ Division case
```

Then:

```text
12 / 4
= 3
```

So the output is:

```text
12 / 4 = 3
```

For every operator, a different `case` is executed:

```text
+ → Addition
- → Subtraction
* → Multiplication
/ → Division
% → Modulo
```

A `break` statement is used after each case to stop the switch from continuing into the next case.

The program also handles **division by zero** safely instead of performing an invalid division.

## 🎯 What I Learned From This Problem

* `switch-case` statements

* Addition and subtraction
* Multiplication and division
* Modulo operator `%`
* Working with characters

* Menu-driven programming
* Step-by-step decision making

This problem helped me understand how **switch-case can be used to select different operations based on an operator character**.
