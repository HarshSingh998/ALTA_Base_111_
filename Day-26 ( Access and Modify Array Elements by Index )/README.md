## 💡 Problem: Access and Modify Array Elements by Index

**Difficulty:** Easy
**Topic:** Arrays Basics • Array Indexing • Modifying Elements

### 🧠 What I Learned

Today I learned how to **access and modify array elements using their index**.

Every element in an array has a specific index, and indexing starts from `0`. We can use the index to read a particular element or change its value.

### 🔄 Basic Logic

If:

```text
Array = {10, 20, 30, 40, 50}
````

The elements are stored at:

```text
Index:   0   1   2   3   4
Value:  10  20  30  40  50
```

To access an element:

```text id="qj1p5d"
arr[2]
```

The value at index `2` is:

```text id="u4k2xv"
30
```

We can also modify the value at an index:

```text id="z4a8vf"
arr[2] = 100;
```

Now the array becomes:

```text id="y2n7ks"
10 20 100 40 50
```

The main idea is to **use the array index to directly access or modify a specific element**.

## 🎯 What I Learned From This Problem

* Arrays
* Array indexing
* Index starts from `0`
* Accessing array elements
* Modifying array elements
* Assigning new values
* Using `arr[index]`
* Working with individual elements
* Understanding array positions

This problem helped me understand how **array indexes allow us to directly access and modify individual elements without changing the entire array**.
