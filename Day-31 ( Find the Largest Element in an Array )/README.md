## 💡 Problem: Find the Largest Element in an Array

**Difficulty:** Easy
**Topic:** Arrays • Basic Math • Array Traversal

### 🧠 What I Learned

Today I learned how to **find the largest element in an array** by comparing each element with the current largest value.

We can start by assuming the first element is the largest and then check the remaining elements one by one.

### 🔄 Basic Logic

If:

```text
Array = {10, 25, 7, 42, 18}
```

First, assume the first element is the largest:

```text
largest = 10
```

Then compare each element:

```text
25 > 10 → largest = 25
7  > 25 → No change
42 > 25 → largest = 42
18 > 42 → No change
```

Finally:

```text
Largest = 42
```

The basic logic is:

```text
for each element in the array
    if element > largest
        largest = element
```

So the output is:

```text
42
```

The main idea is to **traverse the array and continuously update the largest value whenever a bigger element is found**.
